[b]Map Markers Enhanced[/b] adds a redrawn set of 113 map markers to Core Keeper 1.3, right in the game's own map-marker dialog — after the art of moorowl's [b]MapMarkers+[/b]. It also gives back the markers MapMarkers+ players lost in the 1.3 update, when every one of them turned into the same yellow question mark.

[h2]Seven extra marker icons[/h2]
Pick an icon in the upper row of the marker dialog, then the marker in the lower one. The mod's icons sit after the game's own:
[list]
[*][b]General[/b] (18) — exclamation mark, music note, arrows, chest, sign, structures, leaf, fish, cog, heart, flames, shield, dagger, axe
[*][b]Ores[/b] (11) — from Copper to Relucite, and the radiation crystal
[*][b]Flags[/b] (14 colours)
[*][b]Tapestry[/b] (15) — the game's banners, unpainted and in every colour
[*][b]Orbs[/b] (19) — the game's orbs, from empty through every colour to gold, lava and flower
[*][b]Numbers[/b] (0–9)
[*][b]Letters[/b] (A–Z)
[/list]
Every marker has its own small sprite on the minimap. Everything else is the game's own: naming a marker, the five presets, multiplayer and saving work exactly as they do for vanilla markers. When you open a preset that uses one of the mod's icons, the dialog scrolls to it.

[h2]Coming from version 1.x[/h2]
Version 2.0.0 replaces the five 1.x icons with the seven new ones. Markers you placed with a 1.x icon are rewritten to the same-named marker of the new set wherever the world runs with the mod (single-player, the host, or a dedicated server that has it). The question mark, cross, skulls and blue diamond are the game's own markers since 1.3, so those five become the game's own. Presets that use any of them are rewritten on your own computer, whichever server you play on.

[b]Update everyone who shares a world or a server with you.[/b] A dedicated server without the mod converts nothing, and players on 1.x see markers of the new set as a plain blue diamond until they update.

[h2]Your old MapMarkers+ markers come back[/h2]
Core Keeper 1.3 converted every marker drawn with MapMarkers+'s own art into the same question mark — but the original type survived in the save. The first time a world is loaded with this mod on the side that runs it (single-player, the host, or a dedicated server that has the mod), each of those question marks gets its original icon back, once, and the result is saved with the world.

[b]Back up the world first[/b] if you might want the question marks back: after restoring, nothing in the world records which MapMarkers+ marker a restored marker used to be.

[h2]Requirements[/h2]
Core Keeper 1.3. No other mods. MapMarkers+ itself does not load on 1.3 and is best disabled.

[h2]Multiplayer[/h2]
Everyone who wants to see the mod's icons needs the mod. A server that has the mod requires it from every joining player. On a server without the mod you can still join and place markers with the mod's icons; they are saved and survive a server restart, but players without the mod do not see their icons, and old MapMarkers+ markers are not restored there.

[h2]Known limitations[/h2]
[list]
[*][b]A placed marker cannot be edited[/b] — that is Core Keeper 1.3's own behaviour: delete it and place a new one.
[*][b]Uninstalling:[/b] markers that use the mod's icons lose them without the mod; reinstalling brings them back.
[/list]
